# 재사용 가능한 홈페이지 디자인

`asset/{홈페이지특징}` 아래에 원본 디자인, 로컬 실행본과 스킬 지침을 보관합니다.

| 패키지 | 특징 | 사용법 |
| --- | --- | --- |
| `minimal-blue-bilingual-portfolio` | 미니멀 블루, 한·영 전환, 다크 모드, 포트폴리오 카드와 경력 타임라인 | [Windows PowerShell / Ubuntu Bash 실행 안내](asset/minimal-blue-bilingual-portfolio/readme.md) |

홈페이지는 각 패키지의 `assets/site/index.html`을 브라우저에서 열면 됩니다. 새 프로젝트로 복사할 때는 Windows의 `scripts/reuse.ps1` 또는 Ubuntu/WSL의 `scripts/reuse.sh`를 사용합니다. 자동화 작업의 재사용 지침은 각 패키지의 `SKILL.md`에 있습니다.
