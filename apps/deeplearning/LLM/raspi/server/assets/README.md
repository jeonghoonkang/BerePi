# OCR example

`neural-network.png` is the unmodified 1280px Wikimedia Commons PNG rendering of
[Neural Network.svg](https://commons.wikimedia.org/wiki/File:Neural_Network.svg).

- Creator: QuantuMechaniX8 (2025-05-25)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Download: https://thumb.wikimedia.org/wikipedia/commons/thumb/1/15/Neural_Network.svg/1280px-Neural_Network.svg.png
- Retrieved: 2026-09-26
- Visible labels include `Input x`, `Output y`, and layer weights/biases/activations.
  Formula and subscript recognition depends on the installed vision model.

Bundled locally so loading the example needs no third-party request. User uploads
are not written to this directory.
