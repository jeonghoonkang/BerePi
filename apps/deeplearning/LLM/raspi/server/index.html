Clipboard Image OCR · 이미지에서 텍스트 추출

로그인 후 아래 영역을 클릭하고 이미지를 Ctrl+V / ⌘V로 붙여넣으세요. 파일 선택이나 드래그 앤 드롭도 가능합니다.

이미지를 여기에 붙여넣거나 끌어 놓으세요.

PNG · JPEG · WebP, 원본 최대 10 MiB. 전송 시 최대 2048px · PNG 2 MiB로 제한합니다.

HTTP 접속에서 클립보드 버튼이 지원되지 않으면 Ctrl+V 또는 파일 선택을 이용하세요. 이미지는 서버 파일로 저장하지 않습니다.

기본으로 Gemma 4가 이미지를 인식합니다. Tesseract는 직접 선택한 요청에서만 실행하며 자동으로 전환하지 않습니다.

추출한 텍스트가 여기에 표시됩니다.
흐리거나 작은 글자는 잘못 인식할 수 있습니다. 긴 문서가 잘리면 나누어 전송하세요.
