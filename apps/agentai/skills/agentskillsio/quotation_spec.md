# LLM 기반 비정형 기업 데이터 처리 라이브러리

## 1. 품목 개요

| 항목 | 규격 |
|---|---|
| 품명 | LLM 기반 비정형 기업 데이터 처리 라이브러리 |
| 공급 형태 | 소프트웨어 라이브러리 및 업무별 스킬 패키지 |
| 수량 / 단위 | 1식 |
| 용도 | 기업 문서·이미지 등 비정형 데이터의 추출·구조화, LLM 기반 문서 작성·검토 및 결과물 생성 |
| 구성 | 문서 파싱·OCR, LLM 연계, 문서 처리, 연구·글쓰기, 웹 결과물 생성·검증 및 스킬 확장 모듈 |

## 2. 세부 기능 규격

| 번호 | 구분 | 모듈 / 기준 항목 | 요구 규격 |
|---|---|---|---|
| 01 | 문서 추출 | Docling | PDF, DOCX, PPTX, XLSX, HTML 및 이미지 문서의 파싱을 지원하여야 한다. 문서 형식별 추출 가능 범위에 따라 본문, 제목, 표 및 읽기 순서를 구조화하고 Markdown·JSON 형식으로 변환할 수 있어야 한다. |
| 02 | 이미지 문자 인식 | image-ocr | Tesseract 및 Python 기반으로 JPG·JPEG·PNG·WEBP 이미지의 문자 추출, 언어 설정, 이미지 전처리 및 일괄 처리를 지원하여야 한다. 결과는 처리 성공 여부, 파일명, 추출 텍스트, 신뢰도, 메타데이터 및 경고 정보를 포함하는 JSON으로 제공하여야 한다. |
| 03 | LLM 연계 | claude-api | Claude API 및 SDK 연계를 지원하여야 한다. 모델·생성 파라미터 설정, 스트리밍 응답, 도구 호출, 토큰 사용량 확인 및 API 오류 처리를 지원하여야 한다. |
| 04 | 결과 검토 | discernment-nudge | 생성 결과에 포함된 핵심 사실, 가정 및 누락된 맥락의 점검을 지원하고, 사용자 확인이 필요한 사항과 후속 질문을 제시할 수 있어야 한다. |
| 05 | 문서 공동 작성 | doc-coauthoring | 요구사항·참고자료 수집, 목차 구성, 초안 작성, 수정 및 독자 관점 검토로 이어지는 단계별 문서 작성 절차를 제공하여야 한다. |
| 06 | Word 처리 | docx | DOCX 문서 읽기·생성·편집을 지원하여야 한다. 제목, 문단, 표, 목록, 머리글·바닥글 및 템플릿 서식을 적용하고 결과 파일을 검증할 수 있어야 한다. |
| 07 | PDF 처리 | pdf | PDF의 텍스트·표·이미지 추출, 문서 생성, 병합·분할·회전, 워터마크 삽입, 양식 입력 및 스캔 문서 OCR을 지원하여야 한다. |
| 08 | 발표자료 처리 | pptx | PPTX 읽기·생성·편집을 지원하여야 한다. 슬라이드 구성, 텍스트·표·이미지 배치, 템플릿·레이아웃 적용 및 발표자 노트 처리를 지원하여야 한다. |
| 09 | 스프레드시트 처리 | xlsx | XLSX·CSV·TSV 읽기·생성·편집을 지원하여야 한다. 데이터 정제·변환·집계, 수식 작성, 셀 서식 적용, 표·차트 생성 및 계산 결과 검증을 지원하여야 한다. |
| 10 | 화면 설계 | frontend-design | 문서 처리 결과를 표시하는 웹 화면의 레이아웃, 색상, 글꼴 및 UI 구성요소 설계를 지원하여야 한다. |
| 11 | 외부 시스템 연계 | mcp-builder | Python 또는 TypeScript 기반 MCP 서버 구현을 위한 모듈·예제를 제공하여야 한다. 외부 API·서비스 연계를 위한 도구 정의, 입력값 검증, 인증 연계 및 오류 처리를 지원하여야 한다. |
| 12 | 스킬 확장 | skill-creator | 업무별 스킬 신규 작성·수정, 메타데이터·실행 지침 정의, 참고자료·스크립트 구성 및 평가 사례를 통한 개선을 지원하여야 한다. |
| 13 | 공통 테마 | theme-factory | 문서·슬라이드·HTML 결과물에 공통 색상·글꼴·스타일을 적용할 수 있어야 한다. 사전 정의 테마 선택 및 사용자 지정 테마 구성을 지원하여야 한다. |
| 14 | 웹 결과물 생성 | web-artifacts-builder | React, Tailwind CSS 및 shadcn/ui 기반 웹 결과물 생성을 지원하여야 한다. 복합 화면 구성, 상태 관리 및 화면 간 이동 기능 구현을 지원하여야 한다. |
| 15 | 웹 기능 검증 | webapp-testing | Playwright 기반 웹 화면 기능 및 사용자 흐름 검증을 지원하여야 한다. 화면 캡처, 브라우저 로그 및 테스트 결과를 제공할 수 있어야 한다. |
| 16 | 연구문서 작성 | research-paper-writing | 연구 목적·문제 정의, 관련 연구, 방법, 결과 및 논의 중심의 논문 구성·초안 작성을 지원하여야 한다. 제공된 자료에 근거한 인용 및 참고문헌 정리를 지원하여야 한다. |
| 17 | 쉬운 문장 작성 | plain-writing-skill | 대상 독자에 맞춘 용어 설명, 긴 문장 분리, 중복 표현 정리 및 핵심 내용 중심의 문장 개선을 지원하여야 한다. |
| 18 | 콘텐츠 제작 | content-creation-publisher | 원천자료 기반 콘텐츠 기획, 초안 작성, 편집 및 게시용 제목·본문·요약·메타데이터 생성을 지원하여야 한다. |

## 3. 공통 기술 규격

| 항목 | 요구 규격 |
|---|---|
| 모듈 구성 | 문서 추출, OCR, LLM 연계, 문서 생성, 글쓰기 및 웹 결과물 기능을 모듈 단위로 구성하고 업무 흐름에 따라 조합할 수 있어야 한다. |
| 스킬 패키지 | 스킬별 디렉터리에 SKILL.md를 제공하여야 한다. YAML 메타데이터에 name·description을 정의하고 실행 지침을 포함하여야 하며, 필요에 따라 scripts/, references/, assets/를 구성하여야 한다. |
| 입출력 추적 | 입력 파일과 결과를 연결하는 식별정보, 처리 상태, 오류 및 경고 정보를 제공하여야 한다. |
| 환경 설정 | API 키, 모델, OCR 언어 및 파일 경로 등 실행 설정을 외부 설정으로 관리할 수 있어야 한다. API 키를 소스코드에 고정하여 배포하지 않아야 한다. |
| 실행 환경 명시 | 납품 문서에 지원 운영체제, 실행 런타임·패키지 버전, OCR 언어팩 및 문서 변환·재계산에 필요한 외부 도구를 명시하여야 한다. |
| 결과 검증 | 출력 파일의 정상 열기, 필수 데이터 존재 여부, JSON 구조, 주요 수식 계산 및 웹 사용자 흐름을 기능별로 검증할 수 있어야 한다. |
| 작성 근거 관리 | 연구·글쓰기 결과는 제공된 자료에 근거하여 작성하고, 근거가 확인되지 않은 사실·수치·실험 결과 및 인용정보는 확인 필요 항목으로 표시하여야 한다. |

## 6. 견적 적용 조건

1. 본 규격의 공급 수량은 라이브러리 및 스킬 패키지 1식으로 한다. 완성형 업무 시스템의 구축, 개별 기업 시스템 연계 및 운영 서비스 범위는 견적 내역에 별도로 명시한다.
2. 서버·GPU 등 인프라 비용, LLM API 사용료, 외부 서비스 이용료 및 유료 소프트웨어 비용의 포함 여부를 견적서에 명시한다.
3. 외부 게시 채널 자동 게시 및 개별 외부 시스템의 실제 연동 개발은 대상 서비스·인증 방식·연동 기능을 별도로 확정한다.
4. OCR 지원 언어, 처리 정확도, 처리시간, 최대 파일 크기, 동시 처리량 및 지원 실행 환경은 대상 문서와 장비 조건을 기준으로 계약 시 확정한다. 본 규격은 미측정 성능 수치를 보장값으로 설정하지 않는다.
5. OCR 신뢰도는 검토를 위한 보조 지표로 사용하며, 실제 문자 인식 정확도와 구분한다. 표·필기 여부 및 언어 감지 메타데이터는 실제 분석 기능이 적용된 범위에서 제공한다.
6. 문서 변환 시 원본 레이아웃·수식·차트·특수 개체의 보존 범위는 합의된 샘플을 기준으로 확정한다.
7. 납품 시 적용 오픈소스·스킬·모델별 라이선스와 재배포 조건을 확인하여 구성요소 목록에 명시한다.
8. 납기, 설치·교육, 하자보수 기간 및 유지보수 범위는 견적서 또는 계약 조건에 별도로 명시한다.

## 7. 규격 작성 근거

- 내부 기준 문서: 동일 폴더의 [Agent Skills 지원 스킬 명세](spec_skill.md)
- 문서 파싱 참고: [Docling](https://github.com/docling-project/docling)
- 이미지 OCR 참고: [Image OCR SKILL.md](https://github.com/benchflow-ai/skillsbench/blob/main/tasks/jpg-ocr-stat/environment/skills/image-ocr/SKILL.md)

본 문서는 견적·납품 요구사항을 정의하는 규격서이며, 기존 구현의 완료 또는 성능 검증 결과를 나타내는 문서가 아니다. 세부 기능 규격 중 16~24번 연구·글쓰기 항목은 내부 기준 문서에 상세 설명이 없어 요청된 명칭과 용도에 따라 정의한 납품 요구사항이다. 각 명칭은 기능 구분을 위한 기준 항목이며, 특정 공개 패키지의 동일성이나 라이선스를 보증하지 않는다.
