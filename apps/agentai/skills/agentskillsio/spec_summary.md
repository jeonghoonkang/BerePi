## 2. 공통 기능

| 항목       | 요구 규격                                                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 모듈 구성 기능 | 문서 추출, OCR, LLM 연계, 문서 생성, 글쓰기 및 웹 결과물 기능을 모듈 단위로 구성하고 업무 흐름에 따라 조합                                                                                        |
| 스킬 패키지   | 스킬별 디렉터리에 SKILL.md 제공<br>YAML 메타데이터 name·description 정의, 실행 지침 포함<br>scripts/, references/, assets/ 구성 |
| 입출력 추적   | 입력 파일과 결과를 연결하는 식별정보, 처리 상태, 오류 및 경고 정보 제공                                                                                                                 |
| 환경 설정    | API 키, 모델, OCR 언어 및 파일 경로 등 실행 설정을 외부 설정으로 관리<br>                                                                                |
| 실행 환경    | 지원 운영체제, 실행 런타임·패키지 버전, OCR 언어팩 및 문서 변환·재계산에 필요한 외부 도구 제공                                                                                                  |
| 결과 표현    | 출력 파일의 열기, 필수 데이터 존재 여부, JSON 구조, 주요 수식 계산 및 사용자 흐름 제공                                                                                                     |
| 작성 근거 관리 | 생성한 글쓰기 결과는 제공된 자료에 근거하여 작성<br>근거가 확인되지 않은 사실·수치·실험 결과 및 인용정보는 확인 필요 항목으로 표시                                                     |

| 문서 파싱       | 입력 문서에서 지정된 본문·표 등의 정보를 추출 및 Markdown·JSON 결과 생성 |
| :---------- | :----------------------------------------------- |
| 이미지 OCR     | 합의된 언어·품질의 샘플 이미지에서 텍스트를 추출하고 처리 상태·신뢰도·경고 정보 제공 |
| LLM 연계      | 유효한 API 인증정보를 사용하여 요청·응답, 스트리밍 및 도구 호출 제공        |
| 문서 생성       | DOCX·PDF·PPTX·XLSX 결과 파일이 정상적 처리되어 지정된 내용·서식 반영  |
| 생성 및 작성     | 모듈별 샘플 입력에 대해 요구 구성·문체 결과 항목 제공                  |
| 웹 결과물 및 MCP | 화면 이동·주요 동작과 MCP 도구 호출 정상 동작 제공                  |
| 오류 처리       | 지원하지 않는 형식, 손상된 입력 또는 API 오류 발생 시 실패 상태와 원인 저장   |

## 4. 세부 기능

### 문서 추출

* PDF·DOCX·PPTX·XLSX·HTML·이미지 문서 파싱
* 문서 형식별 추출 가능 범위에 따른 본문·제목·표·읽기 순서 구조화
* Markdown·JSON 형식 변환

### 이미지 문자 인식

* LLM 기반 JPG·JPEG·PNG·WEBP 문자 추출
* OCR 언어 설정 및 이미지 전처리
* 복수 이미지 일괄 처리
* 처리 성공 여부·파일명·추출 텍스트·신뢰도·메타데이터·경고 정보의 JSON 출력

### LLM 연계

* Claude API·SDK 연계
* 모델 및 생성 파라미터 설정
* 스트리밍 응답 및 도구 호출 지원
* 토큰 사용량 확인 및 API 오류 처리

### 문서 작성

* 요구사항 및 참고자료 수집
* 목차 구성 및 초안 작성
* 불필요한 수식어 및 반복 문장 정리
* 구체적이고 명확한 표현으로 수정
* 문장 연결 및 문단 구성 개선
* 문서 목적·독자·문체에 맞춘 수정안 제공
* 생성 결과의 핵심 사실·가정·누락 맥락 점검
* 사용자 확인 필요 사항 표시

### 기술문서 작성

* 연구 목적·문제 정의 기반 구성
* 관련 연구·방법·결과·논의 초안 작성
* 제공 자료에 근거한 인용 및 참고문헌 정리
* 기술 문서 논리 전개 검토
* 전문용어 일관성 검토
* 수치·단위 표현 및 그림·표 설명 검토
* 긴 문장 분리 및 중복 표현 정리
* 핵심 내용 중심의 문장 개선

### 화면 설계

* 문서 처리 결과 표시용 웹 화면 설계
* 레이아웃·색상·글꼴 설계
* UI 구성요소 설계

### 외부 시스템 연계

* Python 또는 TypeScript 기반 MCP 서버 구현 모듈·예제 제공
* 외부 API·서비스 연계용 도구 정의
* 입력값 검증 및 인증 연계
* 연계 오류 처리

### 스킬 확장

* 업무별 스킬 신규 작성·수정
* 메타데이터 및 실행 지침 정의
* 참고자료·실행 스크립트 구성
* 평가 사례 기반 스킬 개선

### 공통 테마

* 문서·슬라이드·HTML 공통 테마 적용
* 색상·글꼴·스타일 통일
* 사전 정의 테마 선택
* 사용자 지정 테마 구성

### 웹 결과물 생성

* React·Tailwind CSS·shadcn/ui 기반 웹 결과물 생성
* 복합 화면 구성
* 상태 관리 및 화면 간 이동 기능 구현

### 웹 기능 검증

* Playwright 기반 웹 화면 기능 검증
* 사용자 흐름 검증
* 화면 캡처 및 브라우저 로그 확인
* 테스트 결과 제공

### 기술 항목 

* 논문 목차 구성 및 장별 초안 작성
* 선행연구 정리
* 연구방법·결과·결론 간 연결 검토
* 지정 논문 양식 적용
* 연구 아이디어·메모·실험자료 기반 개요 작성
* 논문 초안 작성 및 확장
* 추가 근거·검증 필요 사항 표시

### Word 처리

* DOCX 문서 읽기·생성·편집
* 제목·문단·표·목록 서식 적용
* 머리글·바닥글 및 템플릿 서식 적용
* 결과 파일 검증

### PDF 처리

* 텍스트·표·이미지 추출
* PDF 문서 생성
* 문서 병합·분할·회전
* 워터마크 삽입 및 양식 입력
* 스캔 문서 OCR 지원

### 발표자료 처리

* PPTX 읽기·생성·편집
* 슬라이드 구성 및 텍스트·표·이미지 배치
* 템플릿·레이아웃 적용
* 발표자 노트 처리

### 스프레드시트 처리

* XLSX·CSV·TSV 읽기·생성·편집
* 데이터 정제·변환·집계
* 수식 작성 및 셀 서식 적용
* 표·차트 생성
* 계산 결과 검증
