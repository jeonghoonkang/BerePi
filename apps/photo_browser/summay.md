# photo_browser 기본 기능 요약

`photo_browser`는 여러 디렉토리에 흩어진 사진·동영상을 스캔하고, 관리 디렉토리(`managed_root`)에 연도·월별로 복사하여 하나의 라이브러리로 정리하는 도구입니다. 스캔 결과와 관리 복사본의 위치는 JSON DB에 기록합니다. 원본 파일은 그대로 보존합니다.

## 기본 처리 흐름

```text
여러 소스 디렉토리 등록
  → 소스별 스캔 및 JSON DB 갱신
  → 병합 미리보기
  → managed_root에 연도·월별 복사
  → 복사 검증 및 JSON DB 갱신
  → 통합 라이브러리 검색·열람
```

### 1. 여러 소스 디렉토리 등록

웹의 `소스·스캔·병합` 화면에서 디렉토리를 등록하거나, 실행 시 `--directory`를 여러 번 지정합니다.

```bash
python apps/photo_browser/app.py \
  --root /data --db /data/photo_db \
  --directory /data/photos \
  --directory /data/phone \
  --directory /data/camera
```

여러 옵션으로 전달한 디렉토리는 같은 DB의 소스로 등록됩니다. 시작 시 소스마다 기존 등록·신규 추가 여부, 사진·동영상 개수, 용량, 이전 스캔 상태를 출력합니다. 첫 번째 경로는 폴더 탐색 시작 위치로 사용합니다. `--directory` 하나만 지정하면 기존처럼 탐색 시작 위치만 설정합니다.

### 2. 사진·동영상 스캔 및 DB 갱신

각 소스를 스캔해 파일 경로, 크기, 촬영 날짜, 메타데이터, SHA-256 해시를 수집하고 JSON DB에 저장합니다. 여러 소스의 파일을 같은 라이브러리에서 조회할 수 있으며, 이후 다시 스캔하면 변경 사항을 반영합니다.

스캔 단계에서는 관리 디렉토리로 사진을 복사하지 않습니다. 실행 시 수행하는 파일 수·용량 집계도 실제 스캔과는 별도입니다.

### 3. 관리 디렉토리에 연도·월별 저장

`managed_root`를 지정하고 병합 미리보기로 대상 경로를 확인한 뒤 병합을 실행합니다. 실제 저장 구조는 분류·소유자 아래에 연도·월이 이어집니다.

```text
managed_root/
└── family/              # 분류
    └── default/         # 소유자
        ├── 2023/
        │   └── 12/
        │       └── photo.jpg
        └── 2024/
            ├── 01/
            │   └── holiday.jpg
            └── 02/
                └── video.mp4
```

연도·월은 사진의 EXIF 촬영 시각이나 동영상의 촬영 메타데이터를 우선 사용합니다. 해당 정보가 없으면 파일 생성·수정 시각 등 이용 가능한 날짜로 분류하며, 날짜를 알 수 없으면 `unknown/unknown`에 저장합니다.

복사 결과는 크기·해시로 검증합니다. 같은 목적지에 동일한 내용의 파일이 있으면 재사용하고, 이름이 같지만 내용이 다르면 `_중복` 등의 접미사를 붙여 보존합니다.

### 4. 관리 복사본 정보를 DB에 반영

병합 과정에서 관리 복사본의 경로·URI·검증 시각을 DB에 반영합니다. DB에는 원본 위치와 관리 복사본 위치를 함께 기록하고, 분류·소유자·연도·월별 JSON 파일과 검색 인덱스를 갱신합니다. 이를 통해 통합된 사진을 날짜·태그·이벤트·사람 등의 조건으로 검색하고 열람할 수 있습니다.

DB 폴더와 관리 폴더에는 `.photo-browser-location.json`도 저장하여 서로의 위치를 확인할 수 있습니다.

## 사용 순서

1. 여러 소스 디렉토리를 등록합니다.
2. `managed_root`를 확인하거나 원하는 관리 경로로 설정합니다.
3. 각 소스를 스캔해 사진 정보를 DB에 등록합니다.
4. 병합 미리보기로 저장 위치와 복사 대상을 확인합니다.
5. 병합을 실행해 연도·월별 관리 복사본을 만들고 DB를 갱신합니다.
6. 라이브러리 화면에서 통합된 사진·동영상을 검색하고 확인합니다.
